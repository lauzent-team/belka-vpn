# Размещение сервера SleePhy

Это пошаговая инструкция: как поднять релей (сервер) SleePhy на настоящем
сервере в интернете, чтобы приложение работало у всех, а не только на вашем
компьютере. Отдельно — как собрать `.exe` для скачивания.

Всё, что делает сервер, — пересылает зашифрованные сообщения. Он не видит текст
переписки: ключи остаются на устройствах. Здесь только про то, где его держать и
как запустить.

## Сначала: где взять сервер, если иностранной карты нет

| Вариант | Нужна карта | Подходит? |
| --- | --- | --- |
| **Oracle Cloud Always Free** | Иностранная карта (для проверки, списаний нет) | Идеально, но без карты не пройти |
| **Российский VPS** (Timeweb, Beget, Selectel, reg.ru, VDSina, FirstVDS) | Российская карта или СБП | **Да — берите этот путь** |

Если иностранной карты нет — не тратьте время на Oracle, он не примет карту
Мир/российский дебет. Берите российский VPS за ~200–300 ₽/мес. Самый простой
тариф (1 vCPU, 1 ГБ памяти, 10 ГБ диска) для релея более чем достаточен:
он только пересылает байты.

Что важно при заказе:

- **ОС: Ubuntu 22.04 или 24.04** — дальше все команды рассчитаны на неё.
- **Оплата**: у Timeweb и Beget есть оплата российской картой и по СБП. У Beget
  бывает даже оплата с баланса телефона.
- **Публичный IPv4** — почти всегда включён в тариф, проверьте, что он есть.

Дальше шаги одинаковые и для Oracle, и для российского VPS: разница только в
том, как вы попадёте на сервер (по SSH). В панели любого VPS будет «IP-адрес»,
«root-пароль» или «SSH-ключ» — это то, что нужно.

## Шаг 1. Зайдите на сервер

На своём компьютере откройте терминал (PowerShell на Windows) и выполните
(замените IP и пользователя на свои):

```bash
ssh root@ВАШ_IP
```

Первый раз спросит `yes` и пароль. Если вы зашли — вы внутри сервера.

## Шаг 2. Скачайте код SleePhy на сервер

На сервере:

```bash
apt-get update && apt-get install -y git
git clone https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git /opt/sleephy-src
cd /opt/sleephy-src
```

Если репозитория на GitHub ещё нет — загрузите папку проекта любым способом
(`scp`, архив), лишь бы на сервере оказалась папка с файлом `server/index.js`.

## Шаг 3. Установите всё одной командой

Из папки с кодом:

```bash
sudo bash deploy/oracle/install.sh
```

Скрипт сам поставит Node.js и Caddy (веб-сервер с бесплатным HTTPS),
скопирует код в `/opt/sleephy`, создаст пользователя и службы. Он безопасно
запускать повторно — база данных и файлы с паролями не перезапишутся.

## Шаг 4. Пропишите домен и секреты

**Домен.** Нужен домен (можно купить за ~200 ₽/год там же, где VPS). В панели
домена создайте A-запись, указывающую на IP сервера:

```
A   relay   ВАШ_IP
```

Так `relay.вашдомен.ру` будет смотреть на сервер. Caddy получит HTTPS-сертификат
сам, без certbot.

Откройте конфиг Caddy и замените пример на свой домен:

```bash
sudo nano /etc/caddy/Caddyfile     # замените relay.example.com на relay.вашдомен.ру
sudo systemctl reload caddy
```

**Секреты.** Откройте файлы и заполните их:

```bash
sudo nano /etc/sleephy/relay.env
sudo nano /etc/sleephy/pay-adapter.env
```

Самое важное — **токен адаптера платежей**. Он один и тот же в двух местах:

- в `pay-adapter.env` → `PAY_ADAPTER_TOKEN`
- в `relay.env` → `SLEEPHY_PAY_ADAPTER_TOKEN`

Придумайте длинную случайную строку, например:

```bash
openssl rand -hex 16
```

И обратите внимание: `SLEEPHY_PAY_ADAPTER` — это **только адрес**, без токена:

```
SLEEPHY_PAY_ADAPTER=http://127.0.0.1:8791
```

Если добавить токен в адрес, релей обратится по неверному пути и оплата не
сработает. (Это была настоящая ошибка в старой инструкции; теперь она
исправлена и покрыта тестом `test/pay-flow.js`.)

> Пока не готовы принимать деньги — оставьте `SLEEPHY_PAY_PROVIDER=checkout`
> (это значение по умолчанию) или вовсе не задавайте его. Тогда покупка
> открывает встроенную страницу оплаты SleePhy: пользователь нажимает
> «Оплатить» или «Отмена», реальные деньги не списываются, а покупка
> зачисляется только после подтверждения. Значение `mock` (мгновенное
> зачисление) оставлено только для автотестов.

## Шаг 5. Перезапустите и проверьте

```bash
sudo systemctl restart sleephy-relay sleephy-pay-adapter
curl -s http://127.0.0.1:12000/health     # {"ok":true,...}
curl -s https://relay.вашдомен.ру/health  # то же самое через интернет
```

Если второй `curl` вернул тот же ответ — сервер в интернете работает.

## Шаг 6. Откройте порты 80 и 443

Если у вашего VPS включён файрвол, разрешите веб-трафик. В панели Oracle это
«Security List» → добавить Ingress для TCP 80 и 443. На самом сервере:

```bash
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save
```

Порты 12000 и 8791 наружу открывать **не нужно** — они слушают только localhost,
снаружи их закрывает Caddy. Так платёжный адаптер недоступен посторонним.

## Шаг 7. Подключите приложение к серверу

В приложении SleePhy на экране входа укажите адрес сервера:

```
wss://relay.вашдомен.ру
```

(`wss://` — это защищённое WebSocket-соединение; Caddy сам его обслуживает.)

Готово: теперь приложение работает у всех, у кого есть `.exe`.

## Как собрать `.exe` для скачивания

Сборка делается **на вашем компьютере**, не на сервере.

На Windows, из папки проекта:

```bash
npm install
npm run dist:win
```

Появится файл:

```
dist/SleePhy-Setup-0.16.2.exe
```

Это и есть установщик: человек скачивает его, запускает, ставит приложение.

Чтобы раздать его через сам сервер, положите `.exe` в папку `dist` на сервере —
релей отдаёт страницу скачивания и файл сам:

```bash
# на вашем компьютере
scp dist/SleePhy-Setup-0.16.2.exe root@ВАШ_IP:/opt/sleephy/dist/
```

Тогда `https://relay.вашдомен.ру` покажет страницу скачивания с кнопкой.

## Обновление версии

Когда вы изменили код, заново загрузите его на сервер и перезапустите:

```bash
cd /opt/sleephy-src && git pull
sudo bash deploy/oracle/install.sh      # безопасно повторять
sudo systemctl restart sleephy-relay
```

## Если что-то не так

| Симптом | Что проверить |
| --- | --- |
| `502 Bad Gateway` | `sudo systemctl status sleephy-relay` — служба упала? |
| Сайт не открывается | DNS: A-запись домена указывает на IP? Порты 80/443 открыты? |
| Нет HTTPS | `sudo journalctl -u caddy -n 50` — Caddy не смог получить сертификат |
| Оплата не зачисляется | Токен совпадает в обоих `.env`? `SLEEPHY_PAY_ADAPTER` без токена в адресе? |
| Приложение не подключается | Адрес начинается с `wss://`? `curl https://домен/health` отвечает? |

Полезные команды:

```bash
sudo systemctl status sleephy-relay
sudo journalctl -u sleephy-relay -n 100 --no-pager
sudo journalctl -u sleephy-pay-adapter -n 100 --no-pager
```
