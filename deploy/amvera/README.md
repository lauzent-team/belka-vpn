# Amvera: переменные и этап сборки

Короткая шпаргалка для деплоя релея SleePhy на Amvera. Полная инструкция по
хостингам — в [`../free/README.md`](../free/README.md).

## Какой этап брать: сборка или запуск

Ни то, ни другое. На Amvera **не нужно выбирать этап вручную**.

Amvera читает `amvera.yaml` из корня репозитория. В нём написано, что окружение
— `docker` и что образ собирается по `deploy/free/Dockerfile`. Поэтому Amvera:

1. на этапе **сборки** сама строит образ по нашему Dockerfile;
2. на этапе **запуска** сама запускает `CMD ["node", "server/index.js"]`.

Кнопки «этап сборки» из CI-настроек (Northflank, GitHub Actions) здесь не нужны
— Amvera делает это сама при нажатии «Собрать» / «Пул».

Если у формы всё же есть поле «Целевой этап сборки» — **оставьте пустым**. Наш
Dockerfile одноступенчатый, промежуточных этапов (`builder`, `runtime`) в нём
нет, и любое значение там только сломает сборку.

## Переменные

Файл [`relay.env.example`](relay.env.example) — готовый список переменных.

**Куда вставлять:** проект Amvera → раздел **«Переменные»** → «Добавить
переменные или секрет». Если форма умеет загружать файл, формат — `KEY=VALUE`,
как в этом файле; строки с `#` — комментарии.

Обязательно заменить:

| Переменная | Что вписать |
| --- | --- |
| `YOOMONEY_RECEIVER` | номер кошелька YooMoney, вида `41001XXXXXXXXXX` |
| `YOOMONEY_SECRET` | секрет из YooMoney → Настройки → Уведомления |
| `SLEEPHY_PAY_ADAPTER_TOKEN` | любая длинная случайная строка (`openssl rand -hex 16`) |
| `SLEEPHY_PAY_PUBLIC_URL` | ваш домен Amvera, `https://…` |
| `SLEEPHY_ADMINS` | ваш ник, он же владелец |

Чего добавлять **нельзя**:

- `SLEEPHY_PAY_ADAPTER` — включает режим внешнего адаптера, которого на Amvera
  нет; оплата перестанет работать;
- `SLEEPHY_PAY_DEMO=1` — демо-страница оплаты, зачисляет покупки без денег.

## Порядок включения оплаты

1. Внести переменные в Amvera.
2. **Перезапустить** контейнер — иначе переменные не применятся.
3. Проверить `https://<домен>/health`. Должно быть
   `{"ok":true,"service":"sleephy-relay","payments":"direct"}`.
   Если там `disabled` — переменная не дошла или в ней опечатка.
4. В YooMoney → «Уведомления» указать URL
   `https://<домен>/notify/<SLEEPHY_PAY_ADAPTER_TOKEN>`, метод HTTP.
5. Купить что-то небольшое и убедиться, что ракеты зачислились.

Секреты (`YOOMONEY_SECRET`, `SLEEPHY_PAY_ADAPTER_TOKEN`) в Amvera лучше вносить
как **секреты**, а не обычные переменные: обычные хранятся открытым текстом.
